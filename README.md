# Book Bans Visualization

Data sources: PEN dataset, ISBNdb API, Google Books API, Open Library API, https://hub.arcgis.com/datasets/nces::school-district-boundaries-current/about

For the sunburst view, the chart for the whole country is presented (the default view). It might take a while for the diagram to show up. Click on arcs to delve deeper. Hover over arcs to get more data (esp. books). Recommend adjusting the zoom on your browser.

Code sources:
https://github.com/topojson/topojson
